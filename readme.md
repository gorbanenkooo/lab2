# Задание 1
## Задача 3
### Текст задачи
Имена.
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество. Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.

### Алгоритм решения
1. Создать класс `Name` с полями `lastName`, `firstName`, `middleName`.
2. Реализовать конструктор для инициализации этих полей.
3. Переопределить метод `toString()`, проверяя каждое поле на `null` и пустоту перед добавлением в итоговую строку, чтобы незаданные параметры не участвовали в формировании текста.

# Задание 2
## Задача 2
### Текст задачи
Человек с именем.
Объедините сущности Человек и Имя таким образом, чтобы имя человека задавалось с использованием сущности Имя, а не строки.

### Алгоритм решения
1. Создать класс `Person`, содержащий поля `name` (объект класса `Name`) и `height` (рост).
2. Реализовать конструктор, принимающий объект `Name` и числовое значение роста.
3. Переопределить метод `toString()`, возвращающий строку вида "Name, рост: height".

## Задача 3
### Текст задачи
Человек с родителем.
Измените сущность Человек, добавив ей возможность задавать третий параметр: Отец, где Отец — это тоже Человек. При приведении человека к строковой форме необходимо проверить параметры имени: если нет фамилии, но есть отец с заданной фамилией — унаследовать её; если нет отчества, а у отца есть личное имя — задать отчество как имя отца с суффиксом "ович".

### Алгоритм решения
1. Добавить в класс `Person` поле `father` типа `Person`.
2. Реализовать перегруженный конструктор, принимающий имя, рост и отца.
3. Внутри конструктора реализовать логику автоматического заполнения фамилии и отчества на основе данных отца, если они не были заданы явно.

# Задание 3
## Задача 2
### Текст задачи
Ломаная.
Создайте сущность Ломаная, которая будет представлять собой ломаную линию. Ломаная линия представляет собой набор характеристик: массив Точек, через которые линия проходит.

### Алгоритм решения
1. Создать вспомогательный класс `Point` с координатами `x` и `y`.
2. Создать класс `Polyline`, содержащий массив объектов `Point`.
3. Переопределить метод `toString()` для вывода линии в виде "Линия [T1, T2, ..., TN]".

# Задание 4
## Задача 9
### Текст задачи
Создаем Ломаную.
Измените сущность Ломаная. Ломаная может быть создана без указания каких-либо параметров или с указанием некоторого набора Точек.

### Алгоритм решения
1. Реализовать конструктор по умолчанию для класса `Polyline`, инициализирующий пустой массив точек.
2. Реализовать конструктор с использованием переменного числа аргументов (`Point... points`), позволяющий передавать произвольный набор точек при создании.

# Задание 5
## Задача 7
### Текст задачи
Длина Ломаной.
Измените сущность Ломаная. В любой момент к имеющимся Точкам можно добавить новые Точки, что приводит к получению нового массива, содержащего как старые, так и новые значения. Ломаная должна уметь возвращать свою общую длину.

### Алгоритм решения
1. Реализовать метод `addPoints(Point... newPoints)`, который объединяет существующий массив точек с новыми с помощью `System.arraycopy`.
2. Реализовать метод `getLength()`, вычисляющий сумму длин отрезков между соседними точками с помощью формулы расстояния на плоскости.
